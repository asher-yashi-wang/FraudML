# Data

The IEEE-CIS Fraud Detection dataset is not included in this repository
(competition terms prohibit redistribution; the files total ~1.3 GB).

Download `train_transaction.csv`, `train_identity.csv`,
`test_transaction.csv`, `test_identity.csv` from Kaggle and place them in:

    data/ieee-cis/

See `docs/data.md` and `docs/reproducibility.md` for details.
